# WiFi Speed Test

Application Android de relevé des réseaux Wi-Fi. Elle affiche la puissance, le canal et la bande, et propose une page Canaux pour choisir une fréquence moins occupée.

Les mesures et les images restent sur le mobile. Aucun compte.
